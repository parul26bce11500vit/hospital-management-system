# Hospital Management System

## Project Description

This project is a simple Hospital Management System developed using Python. It allows users to enter patient details, validate a 10-digit phone number, enter doctor charges, select medical services, and generate the total hospital bill.

## Requirements

* Python 3.x
* No external libraries are required.

## How to Run

1. Install Python 3.x on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python "cs project hospital management.py"
```

5. Enter the required information when prompted by the program.

## Features

* Patient details entry
* 10-digit phone number validation
* Doctor charge input
* Medical service selection
* Service charge calculation
* Automatic bill generation
* Total bill calculation

## Technologies Used

* Input and output
